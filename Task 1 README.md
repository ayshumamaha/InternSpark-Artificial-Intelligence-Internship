# ML Classification Project Using Python

## 1. Project Overview

The ML Classification Project is a machine learning application developed using Python to classify data into predefined categories. It uses the Breast Cancer Wisconsin dataset available through Scikit-learn to predict whether a tumor is malignant or benign.

The application performs data preprocessing, divides the dataset into training and testing sets, and trains two classification algorithms: Logistic Regression and Random Forest. It evaluates their performance using accuracy, precision, recall, F1-score, and ROC-AUC.

The project demonstrates supervised machine learning, data preprocessing, model training, cross-validation, performance evaluation, and visualization techniques.

## 2. Objectives

- Develop a supervised machine learning classification model.
- Understand data preprocessing and train-test splitting.
- Implement Logistic Regression and Random Forest algorithms.
- Compare the performance of multiple classification models.
- Evaluate models using accuracy, precision, recall, F1-score, and ROC-AUC.
- Perform cross-validation to assess model performance.

## 3. Tools and Technologies Used

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Dataset:** Breast Cancer Wisconsin Dataset
- **Algorithms:** Logistic Regression, Random Forest
- **Concepts:** Supervised learning, classification, preprocessing, cross-validation, model evaluation

## 4. Features Implemented

- Loads the Breast Cancer Wisconsin dataset.
- Prepares the data for machine learning.
- Splits the dataset into training and testing sets.
- Trains a Logistic Regression model.
- Trains a Random Forest classifier.
- Evaluates both models using multiple classification metrics.
- Performs five-fold cross-validation.
- Generates confusion matrices and ROC curves.
- Compares model performance using visualizations.
- Identifies the better-performing model based on accuracy.

## 5. How to Run the Program

1. Install Python on your system.
2. Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn
```

3. Save the program as `ml_classification.py`.
4. Open a terminal or command prompt.
5. Navigate to the project folder.
6. Execute the following command:

```bash
python ml_classification.py
```

7. The program trains and evaluates the classification models.
8. View the performance metrics and generated graphs.

## 6. Expected Output

The program displays the evaluation results for Logistic Regression and Random Forest. It provides accuracy, precision, recall, F1-score, ROC-AUC, classification reports, and cross-validation scores.

It also generates confusion matrices, ROC curves, and a comparison chart to help identify the better-performing classification model.
